# 기존 개발 Oracle 검증

Docker의 임시 PDB·가상 DDL 실행기는 제거했다. 기존 개발 DB와 사용자의 로컬 서비스 XML을 JUnit에서 직접 사용한다. 준비와 전체 실행 구분은 [개발 검증 안내](development-testing.md)에 있다.

```text
mvn "-Pjava21,db" -Dmobilecert.test.config=conf/sevice-dev.xml test
```

`DEFAULT_DB`로 연결하며 `MOBILE_CERT`의 테이블 접두사와 DB 기준 월을 사용한다. 기존 시퀀스·월별 테이블·조회 가능한 부서 정보가 필요하다. 실제 Oracle JDBC와 KCB DAO로 요청 및 결과를 저장하고 별도 JDBC 조회로 값과 처리 결과를 확인한다. 테이블이나 제약조건을 생성·삭제하지 않는다.

테스트는 새 거래 키를 확보하고 기존 행이 없는지 확인한 후 저장한다. 정리는 해당 실행에서 생성한 거래 키와 소유 표식을 확인한 행에 한정한다. DAO가 내부에서 커밋하므로 정리 SQL을 명시적으로 실행하며 정리 실패도 테스트 실패다. 부서 정보는 조회만 한다.

설정 파일에는 실제 접속정보가 있으므로 Git에서 제외한다. 콘솔·보고서에 설정 원문과 JDBC 비밀값을 출력하지 않는다. `db` 프로파일의 성공은 실제 저장·조회에 대한 증거이며 KCB 네트워크 인증이나 TCP 서버 동작의 검증은 아니다.
